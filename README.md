# How Gorgias sells

A sales tactics analysis of gorgias.com: a mind map of how Gorgias attracts, educates, proves value to, converts and expands ecommerce merchants, with each tactic tagged by sales method (upsell and cross-sell, anchoring, consultative, qualification, value selling, third-party validation) and a MEDDICC website analysis.

Open `index.html` (or the GitHub Pages site for this repo). Tactic data lives in `cards.json`.
